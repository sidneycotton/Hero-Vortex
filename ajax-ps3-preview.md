# Ajax PS3-style prototype

A dedicated Ajax character pipeline has been added under `assets/characters/ajax/` on branch `ajax-ps3-model`.

The current prototype is a stylized, console-era-inspired humanoid: layered blue armor, helmet/visor, plated limbs, red tabard and sword. It intentionally lives outside the legacy bespoke renderer.

This is a visual prototype, not yet the final authored GLB.
